# 历史结果边界

[文档首页](../README.md) · [操作教程](../tutorial.md)

本仓库是工具链的重新实现，不携带历史项目的性能数字。这里只记录哪些类别的历史结果存在、为什么不公开，以及它们与当前仓库的关系。

## 存在但未公开的条目类别

历史项目留存过以下类别的内部记录。它们与私有数据、内部命名或业务配置绑定，未纳入本仓库，也不在本页引用具体数值：

- 最终唤醒模型在固定评测集上的识别率与误触发统计；
- 现场试用与短时回放记录；其证据不足以建立长期现场误唤醒率；
- 历史训练配置的完整配方（数据配比、增强参数组合、训练轮数与阈值选择）；
- 与业务唤醒词绑定的评测样例和错误案例分析。

## 为什么不公开

这些数字依赖未公开的私有数据划分与评测条件；脱离条件引用会误导读者，本仓库的合成链路也不能重现它们。v0.1 的目标是可复现的工具链与接口，不是历史效果的复刻。

## 与本仓库的关系

- 本仓库不复现历史最终模型的完整训练配方；示例配置只演示接口。
- [训练](training.md)与[校准](calibration.md)文档中的参数示例用于说明格式，不是效果建议。README 与[技术报告](../technical_report.md#81-esp32-s3-端侧部署实践)另引用已有 ESP32-S3 实践的处理耗时和短时调度记录；这些是硬件计算证据，不是历史识别率或长期误触发指标。
- 短时合成回放的协议统计（如校准报告中的召回与 FAH）是接口验证输出，不代表长期现场表现。
- 未来若要把某项历史结果公开，须按 [MODEL_PROVENANCE](MODEL_PROVENANCE.md) 与 [DATA_PROVENANCE](../DATA_PROVENANCE.md) 的边界逐项核对证据、来源与脱敏范围，另行记录。
